Get OffSignal

Move a note, link, or small file between phones using only light. No WiFi, no Bluetooth, no account, no internet.

Android

Install the app directly. It is not on the Play Store, so Android will ask you to confirm the install once.

Download the Android app
  1. Tap the download above and open the downloaded .apk file.
  2. Android will warn that this source isn't allowed yet — tap Settings.
  3. Turn on Allow from this source, then go back and tap Install.

iPhone, or no install at all

OffSignal runs fully in the browser — same app, same code.

Open OffSignal in your browser

On iPhone, open it in Safari, tap the Share button, then Add to Home Screen. It then launches like an app and keeps working with no signal.

Why it asks for so little

The Android app requests exactly one permission — the camera, to read the light signal. It does not request internet access at all. Nothing you send ever leaves the two phones.
